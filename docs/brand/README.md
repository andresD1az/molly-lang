# Molly Lang brand assets

The M shares the curved cut and palette of the original course version. Use the full
logo on the project page, and the standalone M at small sizes.

- `molly-lang-logo.svg` and `molly-lang-icon.svg`:
  vector paths on a transparent background, no fonts required.
- `-dark`: color variant for dark backgrounds.
- `-black` and `-white`: monochrome variants.
- PNG exports: 300 px-high wordmark and 16 to 512 px icons.
- `favicon.ico` and `favicon-dark.ico`: six sizes per file.
- `vista-previa.png`: light and dark preview next to the course version.

Main colors: indigo #454685 and teal #197E73.
